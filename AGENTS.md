# Project instructions

- Run the game by opening `index.html` in a browser. This is a plain HTML, CSS, and JavaScript project; no installation, build step, or server is needed.
- Keep changes small and focused on the agreed task. Read `docs/handoff.md` for context, but check it against the current code and the user's latest decisions. Do not implement a new feature until the user has agreed on its behavior and acceptance checks.
- Any new text shown to the player must be in Norwegian Bokmål, including new button labels, messages, and accessibility labels. Leave existing player-facing text unchanged.
- After changing gameplay, check the agreed acceptance criteria in a browser, plus matches, mismatches, move and pair counters, and restarting during a pending mismatch. Use plain JavaScript if additional checks are needed; do not add a test framework without a concrete need. Clearly distinguish checks actually run from conclusions based on reading code.
- When completing a change, update `docs/handoff.md` with relevant decisions, verified behavior, and remaining work. Preserve the distinction between confirmed bugs and suspected issues.
