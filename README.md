# Little Pairs

A small memory matching game that runs in a browser. No install or build step is needed.

## Run

Open `index.html` in a browser. Choose two cards at a time and find all six pairs. Use **New game** to start again.

## Files

- `index.html` — page structure
- `styles.css` — visual design
- `game.js` — game behavior

There is no automated test setup. Try the game in a browser after making a change.
